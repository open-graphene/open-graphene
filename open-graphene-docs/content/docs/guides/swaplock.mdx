Follow the [workspace setup](./index.mdx) first. Choose a WebSocket endpoint you trust for Swaplock and pass it to your application; the SDK does not require a private key for reads.

## Connect and read

Save this as `read-account.ts` in the app created by [Start here](./index.mdx), then run it with that guide's `main.ts`. `nameOrId` accepts an account name or object ID such as `1.2.123`; it is not a private key.

```ts
import { SwaplockClient } from "@open-graphene/chain-swaplock-api";
import { CHAIN } from "@open-graphene/chain-swaplock-bindings";

export async function readAccount(endpoint: string, nameOrId: string) {
  const client = await SwaplockClient.connect([endpoint], {
    expectedChainId: CHAIN.chainId,
  });

  try {
    const account = await client.database.account(nameOrId);
    const balances = await client.database.accountBalances(account.id);

    return {
      account,
      balances,
    };
  } finally {
    client.close();
  }
}
```

## Network identity

Swaplock requires an explicit trusted `expectedChainId`. `CHAIN.chainId` selects the bundled testnet. For another deployment, supply its trusted chain ID; do not learn that expected value from the node you are about to trust. The client verifies network identity on connection and reconnection. The current React adapter is restricted to the bundled network.

The returned balance amounts are raw integers. Continue with [Read and display data](./reads.mdx) to resolve asset symbols and format them.

## Use React

Use `SwaplockProvider` and hooks from `@open-graphene/chain-swaplock-react`. Mount the chain provider inside `QueryClientProvider`, passing an already connected `SwaplockClient`. Your application owns the connection and closes it when it is no longer needed.

The [React guide](./react.mdx) explains query state, live reads, mutation hooks and prefetching.

## Methods and operations

The client groups RPC methods under namespaces such as `database`, `history`, `crypto`, `orders` and `networkBroadcast`. The [SwaplockClient reference](../reference/swaplock/typescript/classes/SwaplockClient.md) lists the actual members of each namespace, with parameter and return types.

Use `client.transaction()` for a transaction builder or `client.prepareOperations(...)` to prepare existing operations. Preparation, signing, broadcast and inclusion are separate steps; see [Transactions](./transactions.mdx).
