Follow the [workspace setup](./index.mdx) first. Choose a WebSocket endpoint you trust for BitShares and pass it to your application; the SDK does not require a private key for reads.

## Connect and read

```ts
import { BitSharesClient } from "@open-graphene/chain-bitshares-api";

export async function readAccount(endpoint: string, nameOrId: string) {
  const client = await BitSharesClient.connect([endpoint]);

  try {
    const account = await client.database.account(nameOrId);
    const balances = await client.database.accountBalances(account.id);

    return {
      account,
      balances,
    };
  } finally {
    client.close();
  }
}
```

The client uses the chain identity bundled with its bindings and verifies the connection. Select endpoints for that chain.

## Use React

Use `BitSharesProvider` and hooks from `@open-graphene/chain-bitshares-react`. Mount the chain provider inside `QueryClientProvider`, passing an already connected `BitSharesClient`. Your application owns the connection and closes it when it is no longer needed.

The [React guide](./react.mdx) explains query state, live reads, mutation hooks and prefetching.

## Methods and operations

The client groups RPC methods under namespaces such as `database`, `history`, `crypto`, `orders` and `networkBroadcast`. The [BitSharesClient reference](../reference/bitshares/typescript/classes/BitSharesClient.md) lists the actual members of each namespace, with parameter and return types.

Use `client.transaction()` for a transaction builder or `client.prepareOperations(...)` to prepare existing operations. Preparation, signing, broadcast and inclusion are separate steps; see [Transactions](./transactions.mdx).
