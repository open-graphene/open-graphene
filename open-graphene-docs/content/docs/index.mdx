---
title: What is Open Graphene?
description: SDK tooling for Graphene-based blockchains.
---

Open Graphene turns blockchain protocol definitions into tools that applications can use.
It extracts a machine-readable specification from a chain's C++ sources, then generates Rust and TypeScript bindings from that specification.

## Supported chains

The project includes tooling for **Swaplock**, **BitShares**, and **R-Squared**.
Available features vary by chain and language; Swaplock has the broadest SDK coverage.
