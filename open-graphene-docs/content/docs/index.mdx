Use Open Graphene to read blockchain data, build live React screens and prepare transactions on **BitShares**, **Swaplock** or **R-Squared**.

## New to the SDK? Start here

1. [Run your first TypeScript account read](./guides/index.mdx): create an app, connect and print balances.
2. [Display useful balances](./guides/reads.mdx): resolve assets and format raw amounts.
3. [Build a live React screen](./guides/react.mdx): connect the client, mount providers and handle loading and errors.
4. [Prepare and send a transaction](./guides/transactions.mdx): review a transfer, sign it and observe inclusion.

Reads require a node endpoint and an account name. Sending a transaction additionally requires signing authority. Start with the read-only walkthrough before adding a wallet.

## Build an application

Start with [workspace setup](./guides/index.mdx), then follow [React integration](./guides/react.mdx) or the [transaction lifecycle](./guides/transactions.mdx).

The [complete API reference](./reference/index.md) follows the public exports of all three SDKs and their [shared packages](./reference/shared/index.md). It covers methods, hooks, providers, options factories, operations, codecs and types. Signatures and source links are generated from the repository at build time.

The current reference covers TypeScript and React. See [Toolchain](./toolchain.mdx) for the wider project architecture and the [repository](https://github.com/open-graphene/open-graphene) for source code.
