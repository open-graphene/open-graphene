---
title: What is Open Graphene?
description: TypeScript and React SDKs for BitShares, Swaplock and R-Squared.
---

Open Graphene turns blockchain protocol definitions into application tools. It extracts a machine-readable specification from a chain's C++ sources and generates typed bindings from it.

## Build an application

Start with [workspace setup](./guides/index.mdx), then follow [React integration](./guides/react.mdx) or the [transaction lifecycle](./guides/transactions.mdx).

The [complete API reference](./reference/index.md) follows the public exports of all three SDKs and their [shared packages](./reference/shared/index.md). It covers methods, hooks, providers, options factories, operations, codecs and types. Signatures and source links are generated from the repository at build time.

The current reference covers TypeScript and React. See [Toolchain](./toolchain.mdx) for the wider project architecture and the [repository](https://github.com/open-graphene/open-graphene) for source code.
